Sets the time zone for displaying and interpreting time stamps. If not explicitly set, the server initializes this variable to the time zone specified by its system environment. See [Time Zones](https://www.postgresql.org/docs/9.1/datatype-datetime.html#DATATYPE-TIMEZONES) for more information.
